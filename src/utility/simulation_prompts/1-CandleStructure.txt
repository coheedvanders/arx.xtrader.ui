==================================================
CALCULATIONS
==================================================

For every candle:

range:
    high - low

body:
    abs(close - open)

upperWick:
    high - max(open, close)

lowerWick:
    min(open, close) - low

bodyRatio:
    body / range

upperWickRatio:
    upperWick / range

lowerWickRatio:
    lowerWick / range

closeLocation:
    (close - low) / range

Handle zero range safely.
Never return NaN or Infinity.

==================================================
DIRECTION
==================================================

isBullish:
    close > open

isBearish:
    close < open

If close === open:

    direction = 'NEUTRAL'

Otherwise:

    bullish candle -> 'BULLISH'
    bearish candle -> 'BEARISH'

Do not infer trend from this field.

==================================================
INSIDE BAR
==================================================

A candle is an inside bar when:

current.high <= previous.high
AND
current.low >= previous.low

The first candle must return false.

==================================================
OUTSIDE BAR
==================================================

A candle is an outside bar when:

current.high >= previous.high
AND
current.low <= previous.low

The first candle must return false.

==================================================
ENGULFING
==================================================

Use BODY engulfing, not full-wick engulfing.

Bullish engulfing:

previous candle is bearish
AND
current candle is bullish
AND
current body completely engulfs previous body.

Bearish engulfing:

previous candle is bullish
AND
current candle is bearish
AND
current body completely engulfs previous body.

Do not use future candles.
